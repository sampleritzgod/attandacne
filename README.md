# Attendance Calculator

A simple web app that shows your attendance percentage and tells you how many classes you can skip, or need to attend, to stay above your target (such as 75%).

![Screenshot](docs/images/desktop-light.png)

## Features

- **Quick check:** enter attended and total classes to get your percentage right away.
- **Subject tracker:** mark each class Present or Absent, with undo and dated history.
- **What-if planner:** see your percentage after attending or missing the next few classes.
- **Custom targets** for individual subjects.
- **Backup and export:** JSON backup, CSV spreadsheet or printable report.
- **Light and dark themes,** on desktop and mobile.

## Getting started

No installation is needed. Open `index.html` in any modern browser:

```bash
open index.html
```

Your data is saved in the browser (`localStorage`) and never leaves your device.
